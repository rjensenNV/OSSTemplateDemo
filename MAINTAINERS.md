## Responsibilities

The maintainer reviews and merges contributions, triages issues, and maintains
source releases. The maintainer provides an initial response to public issues and
pull requests within seven calendar days. Resolution and implementation are best
effort.

## Contact and escalation

- Project questions, bug reports, and proposals: GitHub Issues
- Maintainer escalation: comment on the relevant issue or pull request after
  seven calendar days without an initial response
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md)
